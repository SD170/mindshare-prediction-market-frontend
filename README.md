# Frontend

React app with MetaMask integration for interacting with prediction markets.

## Setup

```bash
npm install
```

## Configuration

Create `.env`:
```env
VITE_API_URL=http://localhost:3001
VITE_RPC_URL=https://sepolia.base.org
```

## Run

```bash
npm run dev
```

## Features

- View markets with countdown timers
- Deposit bets (Yes/No or Project A/B)
- Redeem winnings
- View leaderboard
- Token faucet
